LamaScambaseBot
===============

Telegram-бот для поиска и модерации пользовательских жалоб, учёта
наблюдаемых Telegram ID и истории username, обращений в поддержку и
административных уведомлений.

**Версия исходников:** ``2026.11.01-r3.4-transactional-id`` (R3.4).

.. important::

   Наличие опубликованной жалобы не доказывает нарушение или вину человека.
   Перед публикацией требуется модерация; неверные записи необходимо
   иметь возможность обжаловать и снять с публикации.

Возможности
-----------

* Поиск и просмотр опубликованных жалоб, подача жалоб и обжалование.
* Модерация и административные действия с проверкой полномочий.
* Сопоставление Telegram ID и история наблюдаемых username. При подаче
  жалобы можно использовать Telegram-кнопку выбора аккаунта либо переслать
  сообщение с доступными данными об отправителе.
* Защита от ошибочного переноса старых жалоб на нового владельца username:
  неоднозначные исторические связи требуют отдельной проверки.
* История решений по ID, уточнение старых жалоб через ``/clarify``.
* Поддержка: обращения с историей сообщений и ответами администратора.
* Административные рассылки с предпросмотром, форматированием, кнопками,
  очередью отправки и возможностью отказаться от новостей.
* Telegram-оформление через ``TgAndroidIcons`` при поддержке аккаунтом
  и клиентом соответствующих возможностей.

Требования
----------

* Python 3.11+.
* Доступ в интернет для работы с Telegram Bot API.
* Telegram-токен бота от BotFather и собственный Telegram ID администратора.
* SQLite (входит в стандартную библиотеку Python).

Установка для новой, пустой базы
--------------------------------

Выполняйте команды из корня проекта::

    python3 -m venv .venv
    . .venv/bin/activate
    python -m pip install -r requirements.txt
    cp .env.example .env
    chmod 600 .env

Откройте приватный ``.env`` и заполните ``API_TOKEN`` и ``ADMIN_ID``.
Не коммитьте ``.env``. По умолчанию файл базы указан как
``DB_PATH=data/reports.sqlite3``; каталог создаётся при запуске.

Запуск::

    python app.py

Бот использует polling. Не запускайте два экземпляра с одним токеном.
Для системного сервиса есть пример ``deploy/lamascambase.service.example``;
адаптируйте пути и права доступа под свою машину. Пример не предназначен
для прямого копирования без проверки.

Обновление существующей установки
---------------------------------

Перед обновлением остановите один работающий экземпляр и сделайте
согласованную копию SQLite через Backup API, а также резервную копию
приватного ``.env`` и Telegram-сессий. Сначала прогоните миграции на
копии базы, только затем обновляйте рабочую установку. Не заменяйте
действующую базу пустой и не добавляйте пользовательские данные в Git.

Telegram ID: границы возможностей
--------------------------------

Telegram Bot API передаёт достоверный ID пользователя, взаимодействующего
с ботом, и в некоторых случаях ID выбранного аккаунта или отправителя
пересланного сообщения. **Bot API не позволяет по произвольному
``@username`` получить числовой ID человека.**

Для разрешения текущих публичных username опционально поддерживается
MTProto через ``TELEGRAM_API_ID`` и ``TELEGRAM_API_HASH`` в приватном ``.env``.
Без этих параметров остальные функции бота продолжают работать.
Ограничения Telegram должны соблюдаться; сессии и ключи нельзя публиковать.

Даже MTProto не устанавливает прежнего владельца username после его
передачи другому человеку. Исторические жалобы без надёжного подтверждения
не следует связывать с нынешним владельцем автоматически. ID автора
жалобы также не является ID её адресата.

Команды и интерфейс
-------------------

* ``/start``, ``/check``, ``/list`` — главное меню, поиск и список жалоб.
* ``/report`` — подать обращение о предполагаемом нарушении.
* ``/myid`` — узнать собственный ID.
* ``/clarify #123`` — уточнить аккаунт своей старой жалобы.
* ``/support``, ``/tickets`` — поддержка и обращения.
* ``/notifications``, ``/unsubscribe`` — настройка новостных сообщений.

Администратору доступны дополнительные разделы модерации, проверки ID,
рассылок и поддержки. Все права проверяются на стороне бота.

Тесты и проверка публичного архива
---------------------------------

Проверка тестов без отправки сообщений реальным пользователям::

    python -m unittest discover -s tests -v
    python scripts/check_telegram_contract.py
    python scripts/check_hybrid_contract.py
    python scripts/check_identity_dispatch.py
    python scripts/check_release.py

Последние три contract/dispatch-проверки требуют установленных зависимостей;
скрипты не предназначены для использования production-токена.
Проверить уже собранный ZIP отдельно::

    python scripts/check_release.py --archive /path/to/public-source.zip

``check_release.py`` обнаруживает распространённые секреты и приватные
файлы, но не заменяет ручную проверку и не очищает ранее опубликованную
историю Git.

Безопасность и приватность
-------------------------

Никогда не добавляйте в публичный репозиторий ``reports.db``/``*.sqlite3``,
WAL/SHM, ``.env``, токены, API hash, Telegram-сессии, резервные копии,
вложения, реальные сообщения пользователей или рабочие логи. Создавайте
публичный репозиторий из чистой копии исходников, не из production-каталога.

Бот хранит пользовательские жалобы и обращения. Оператор отвечает за
политику хранения, модерацию, обработку запросов на исправление/удаление,
получение необходимых согласий и соблюдение применимых правил.
